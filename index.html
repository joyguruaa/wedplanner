☁️ Auto-save to GitHub

Off

Every change (quotes, payments, screenshots, shopping, logo) saves automatically to a private GitHub repo, so all your devices show the same data.

One-time setup (5 min)
  1. On github.com (as joyguruaa) create a new repository named wedplanner-data. Choose Private. Don't add any files.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → wedplanner-data. Permissions → Repository permissions → Contents: Read and write. Expiration: a date after the wedding.
  4. Generate, copy the token, paste it below and tap Connect.
  5. Do step 4 on every phone/laptop you use, with the same token.

The token stays only on this device; it is never put into the website or the data. Anyone holding it can read and change your data, so share it only with family members you trust.

🔗 Short share links

Shared links are short (like …/wedplanner/#s=Ab3dE9xY…) when GitHub auto-save is connected and a public repo named wedplanner-share exists that your token can write to. Each shared item is stored there encrypted; only someone with the link can read it.

One-time setup
  1. On github.com create a new repository wedplanner-share → Public → tick Add a README.
  2. Open github.com/settings/personal-access-tokens, click your wedplanner token → Edit → Repository access → also select wedplanner-share → Update.
  3. Tap Test below. Your devices keep working with the same token.
